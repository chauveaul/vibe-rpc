Antigravity CLI usage limits

5-hour and weekly quotas (auto-switches between Gemini & 3P pools)
{{if eq .AgyStatusLine "vibe-rpc"}} On: stacked under Antigravity CLI's default status line {{else if eq .AgyStatusLine "other"}} You already have a custom Antigravity CLI status line, so vibe-rpc won't replace it {{else}} Off (showing 5-hour active time fallback) {{end}}
